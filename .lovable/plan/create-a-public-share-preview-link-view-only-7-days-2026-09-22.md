# Create a public share preview link (view-only, 7 days)

No code changes needed — the link is generated from the editor UI.

## Desktop

1. Click the **Share** button in the top-right corner of the editor.
2. Choose **Share preview**.
3. Copy the generated link and send it to anyone — it opens the site in read-only view and needs no Lovable account.

## Mobile

1. Switch to Chat mode, tap the **...** button at the bottom-right, then **Share**.
2. Choose **Share preview** and copy the link.

## Notes

- The link stays valid for **7 days**; a new one can be generated after it expires.
- It is temporary and view-only — it is not the same as publishing, which makes the site permanently live at a public URL.
- The link shows the current state of the preview, so any further edits are included as you make them.
